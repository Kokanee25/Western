# The crowd lab

Game #1303, the AI crowd bake-off: can one-picture AI men (Meshy 7.1, Tripo P2 and H3.1, made in the
Character Studio's `crowd3d`) stand in for MetaHumans in the background crowd? Bridge commands
(`bridge.gd`) put a man of any model walking, standing or sat, hold the private cast off so each
keeps his model, and read each level's triangles. **It changes nothing in the game.** The men it
was made for are not in this repo (the Studio's builds `miner_crowd_*`, laid into a local checkout
for the renders only, until Sean picks).
