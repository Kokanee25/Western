### 2026-11-03 — Gameplay (CI): branch pushes build nothing, the nightlies only when main changed (#504)

`build.yml`: tests and the native plugin run on every push to `main` (export, smoke, release,
Pages as before), on pull requests (opened and each push to them) and on a branch push whose last
commit message says `[build]`; any other branch push is a run with every job skipped (no minutes).
A `[build]` push and its PR's run share a concurrency group, so only one builds. `tour.yml` runs
once a day (05:11 UTC) on the latest green main build, skipping when its video is already on the
`tour` release; `visual.yml` and `nightly.yml` start with a one-minute `changed` job and skip when
main hasn't changed since their last finished run. CLAUDE.md (one rule, the CI bullet) and LAYOUT.md
"CI" say how a session gets a build now. Minutes: was ~21,000 a week (~3,000 a day); a typical day
now (~13 merges, ~13 PRs with ~2 runs each) is ~790 main + ~1,040 PR + ~30 tour + ~180 visual +
~120 soak ≈ 2,150 job-minutes (~15,000 a week); the nightlies cost ~3 minutes on a day main doesn't change. The PRs' macOS
and Windows native jobs (~11 of a PR run's ~40 minutes; macOS bills 10x if private) are the next cut
if wanted.
