# Materials judge, round 2026-11-10_material_r3e

Blind; judged only by eye from the named crops against the six AAA references (RDR2 street noon,
golden and saloon night; Hunt 1896 street noon and saloon night; KCD2 street noon). Wood only.
Crop boxes are `x y w h` in the named file's own pixels.

## R1

Rough-sawn pine, board and batten.

### new
1. Real stuff: **FAIL**. The pine figure reads, but it reads planed and smooth, with no saw kerf or
   fibre fuzz. A regular crosshatch (canvas weave) shows through the figure, so it looks like a
   print on cloth. R1_new_near.png 1050 50 350 400.
2. Age reads: **PASS**. Fresh, clean, yellow pine: clearly the new one.
3. No tile tells: **FAIL**. There is a square weave micro-pattern (R1_new_near.png 1050 50 350 400),
   and the batten gaps are drawn as a stair-stepped sawtooth (R1_new_near.png 60 300 200 200).
4. Board to board: **PASS**. Tone, width and figure differ from board to board without striping.
5. Edges and joints: **FAIL**. Two of the gaps are a hard black sawtooth line instead of a shadowed
   gap. R1_new_near.png 90 0 130 780, 450 0 40 780.
6. Holds at distance: **PASS**. At 5 m the figure and battens hold, with no shimmer
   (R1_new_far.png).

**Grade: game**

### few
1. Real stuff: **PASS**. Grey weathered boards with checks and splits read as wood, especially the
   right-hand board. R1_few_near.png 1200 300 200 480.
2. Age reads: **FAIL**. At 5 m it can hardly be told from old: same orange-grey, same streaks.
   R1_few_far.png 0 20 560 340 against R1_old_far.png 0 20 560 340.
3. No tile tells: **FAIL**. The canvas crosshatch shows in the flat mid-board areas.
   R1_few_near.png 400 250 250 300.
4. Board to board: **PASS**. The boards vary in grey, bleach and checking.
5. Edges and joints: **FAIL**. Every batten edge carries a rust-orange outline, which reads as a
   coloured line drawn on. R1_few_near.png 270 0 120 780 and 1180 0 200 780; R1_few_far.png
   55 20 30 340.
6. Holds at distance: **PASS**. It keeps its weathered streaking at 5 m, with no mush.

**Grade: game**

### old
1. Real stuff: **FAIL**. The grey reads as smudged dry-brush paint over cloth, not checked wood
   fibre. R1_old_near.png 380 450 350 330.
2. Age reads: **FAIL**. It is not distinct from few (see few, check 2). There is no sun-split
   checking or end rot to set old apart, only more smudge.
3. No tile tells: **FAIL**. The weave is everywhere in the flat grey. R1_old_near.png
   380 450 350 330, 0 0 350 400.
4. Board to board: **FAIL**. The five left boards are the same grey with the same blotches.
   R1_old_near.png 0 0 1000 780.
5. Edges and joints: **FAIL**. The batten edges carry the same rust-orange outline.
   R1_old_near.png 930 0 180 780.
6. Holds at distance: **PASS**. It reads as old boards at 5 m (R1_old_far.png).

**Grade: fake**

**Best age:** new.

**The one change that would move it up most:** take the regular crosshatch (canvas-weave)
micro-detail out of the wood's colour and normal, and replace it with along-the-grain fibre and
rough-sawn kerf marks. It is the tell in all three ages, and it makes old read as painted cloth.

## C1

Planed pine lap siding.

### new
1. Real stuff: **FAIL**. Pale and almost figureless: it reads as laminate or plastic, not planed
   pine. C1_new_near.png 0 250 1400 230.
2. Age reads: **PASS**. Clearly fresh, unweathered stock.
3. No tile tells: **FAIL**. Every lap has the same row of sawtooth dashes (C1_new_near.png
   0 95 1400 30, 0 235 1400 30), and the weave grid shows in the boards (C1_new_near.png
   0 120 1400 110).
4. Board to board: **FAIL**. All the boards are one tone, except one board with grain that looks
   pasted in. C1_new_near.png 0 590 1400 110 against 0 250 1400 230.
5. Edges and joints: **FAIL**. The lap's shadow is a repeated row of little triangles, not a
   continuous shadow under the lap. C1_new_near.png 0 235 1400 30.
6. Holds at distance: **FAIL**. A flat orange card with dotted lap lines. C1_new_far.png
   0 0 560 360.

**Grade: fake**

### few
1. Real stuff: **FAIL**. The grey has lavender and blue patches, so it reads as painted. The top
   board is warm figured pine that doesn't belong with the rest. C1_few_near.png 0 100 1400 130
   and 0 0 1400 90.
2. Age reads: **PASS**. Clearly between new and old: greyed, with a couple of fresher boards.
3. No tile tells: **FAIL**. The sawtooth lap shadows (C1_few_near.png 0 235 1400 30) and the weave
   (C1_few_near.png 0 100 1400 120).
4. Board to board: **FAIL**. Below the top board, every board is the same mauve-grey.
   C1_few_near.png 0 240 1400 540.
5. Edges and joints: **FAIL**. A saturated orange band runs along the bottom of every lap.
   C1_few_near.png 0 215 1400 30 and 0 335 1400 40.
6. Holds at distance: **FAIL**. At 5 m it becomes bright orange stripes at every lap.
   C1_few_far.png 0 120 560 240.

**Grade: fake**

### old
1. Real stuff: **FAIL**. A smudgy purple-grey that reads as a painted texture more than
   sun-silvered pine. C1_old_near.png 0 480 1400 120.
2. Age reads: **PASS**. Greyed, with nail rust bleeding, checks and a knot split
   (C1_old_near.png 460 610 60 60). It is believably old.
3. No tile tells: **FAIL**. The sawtooth lap shadow is still on every lap. C1_old_near.png
   0 375 1400 30, 0 600 1400 30.
4. Board to board: **PASS**. The boards vary in tone and weathering.
5. Edges and joints: **FAIL**. Orange bands along the lap edges. C1_old_near.png 0 335 1400 40.
6. Holds at distance: **PASS**. It keeps board-to-board variation and reads as weathered siding at
   5 m (C1_old_far.png).

**Grade: game**

**Best age:** old.

**The one change that would move it up most:** draw the lap as one continuous soft shadow under
the board above, with a slightly worn arris in the same wood. That replaces the sawtooth row of
triangles and the orange stripe on every lap: in all three ages it is the first thing seen near
and far.

## F2

Black walnut tongue and groove, varnished.

### new
1. Real stuff: **FAIL**. The hue is orange-red cherry or mahogany, not walnut's chocolate to
   purple-brown. The figure is smeared, like liquified paint (F2_new_near.png 1000 380 220 340).
   At night it goes nearly black with no varnish highlight (F2_new_saloon_night.png 0 0 1400 780).
2. Age reads: **FAIL**. It cannot be told from few. F2_new_far.png against F2_few_far.png
   0 15 560 310.
3. No tile tells: **PASS**. No repeat or weave at 1 m. On the deck (F2_new_noon_rail.png) the grain
   reads well.
4. Board to board: **PASS**. The boards differ in figure and tone.
5. Edges and joints: **PASS**. The V-grooves read as shadowed joints.
6. Holds at distance: **PASS**. No shimmer, though the even narrow stripes lean toward
   laminate panel (F2_new_far.png).

**Grade: game**

### few
1. Real stuff: **FAIL**. The same orange-red hue, and the wavy figure is stretched and smeared.
   F2_few_near.png 340 0 120 780; F2_few_saloon_night.png 340 0 120 780.
2. Age reads: **FAIL**. No visible change from new: no dulled varnish, no handling marks
   (F2_few_far.png against F2_new_far.png).
3. No tile tells: **PASS**.
4. Board to board: **PASS**.
5. Edges and joints: **PASS**.
6. Holds at distance: **PASS**.

**Grade: game**

### old
1. Real stuff: **FAIL**. Almost black: the figure is lost at noon and gone at night.
   F2_old_near.png 300 0 1100 780; F2_old_saloon_night.png 250 0 1150 780.
2. Age reads: **FAIL**. The only sign of age is darkening (and a craze that shows only when
   brightened). There is no wear where hands and shoulders go and no dulled or rubbed varnish.
   F2_old_near.png 300 200 700 400.
3. No tile tells: **FAIL**. The varnish craze is an even map of thin, equal-weight outlines across
   every board, which reads as a stamped overlay. F2_old_near.png 300 200 700 400.
4. Board to board: **FAIL**. Apart from the left two, the boards are one uniform near-black.
   F2_old_near.png 300 0 1100 780.
5. Edges and joints: **PASS**. The grooves read as shadowed gaps. On the deck the lit arrises read
   as wear (F2_old_noon_rail.png 500 30 1000 250).
6. Holds at distance: **PASS**. At 5 m it reads as darker panelling (F2_old_far.png).

**Grade: game**

**Best age:** new.

**The one change that would move it up most:** regrade the base colour from orange-red to
walnut's cool chocolate-brown, at a higher value. It currently reads as mahogany, and it is so
dark that it goes black at night and at old, which kills the figure and the varnish.

## Summary

- R1: new game / few game / old fake
- C1: new fake / few fake / old game
- F2: new game / few game / old game
