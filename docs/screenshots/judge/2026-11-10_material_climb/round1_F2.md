# Materials judge: F2 (black walnut, narrow tongue and groove, varnished)

Blind judgment of 24 crops (three ages, two sets each) against the wood in the six AAA reference
screenshots. Crop boxes are `x y w h` in the named crop.

Seen once, not counted: the saw-toothed edge of the rail's sun shadow on the floor in every
`noon_rail` crop (a fault of the light).

Common to every swatch and set:
- No varnish reads anywhere. There is no sheen, no highlight roll-off and no depth in the finish
  in any light; the surface is matte. The yardstick's saloon woodwork (RDR2 balcony rail, newels)
  shows a soft specular sheen under the lamps.
- At 5 m in golden light every swatch turns a saturated orange-red and the grain looks smoothed,
  close to a painted card. The colour is the light's, so it is not failed, but the softness is noted.

## F2_new

### Set P
1. Real stuff: PASS (marginal). Dark red-brown with believable cathedral and straight grain at noon; redder than walnut, nearer rosewood.
2. Age reads: FAIL. Not distinguishable from F2_few. Evidence: `F2_new_P_near.png` 0 0 1400 780 beside `F2_few_P_near.png` 0 0 1400 780.
3. No tile tells: PASS at 1 m. Hunted tell: rippled, raised-grain banding on the floor at a grazing angle, `F2_new_P_noon_rail.png` 560 50 800 180.
4. Board to board: PASS. Fine straight boards alternate with coarse cathedral boards.
5. Edges and joints: FAIL. Joints are all but absent at 1 m; the wall reads as one sheet of veneer. `F2_new_P_near.png` 420 0 40 780; floor with no board lines, `F2_new_P_noon_rail.png` 400 200 1200 200.
6. Holds at distance: PASS (soft). `F2_new_P_far.png` keeps figure and board rhythm.

Lamplight: `F2_new_P_saloon_night.png` is near-black with pure red figure; legible, only just.

**Grade: game.**

### Set Q
1. Real stuff: PASS. Chocolate brown with dark streaks, the most walnut-like of the swatch; reads unfinished, not varnished.
2. Age reads: FAIL. Same as F2_few Q. `F2_new_Q_near.png` 0 0 1400 780.
3. No tile tells: PASS at 1 m. Same floor ripple, more visible because lighter: `F2_new_Q_noon_rail.png` 560 50 800 180.
4. Board to board: PASS.
5. Edges and joints: FAIL. Joints nearly invisible: `F2_new_Q_near.png` 420 0 40 780; `F2_new_Q_noon_rail.png` 400 200 1200 200.
6. Holds at distance: PASS (soft). Bright orange at golden hour; reads as pine at 5 m.

Lamplight: `F2_new_Q_saloon_night.png` is clearly readable as figured wood.

**Grade: game.**

**Better set: Q, within a grade** (legible under the lamp; P crushes toward black).

**One change that moves it up most:** give the tongue-and-groove a real shadowed joint (a V or bead with a dark gap) so the wall reads as boards and not a veneer sheet; a varnish sheen is second.

## F2_few

### Set P
1. Real stuff: PASS (marginal). As new P; very dark.
2. Age reads: FAIL. No wear, dust, dulling or handling marks; only faintly more visible joints than new. `F2_few_P_near.png` 0 0 1400 780.
3. No tile tells: PASS.
4. Board to board: PASS.
5. Edges and joints: FAIL. Hairline joints only, flush: `F2_few_P_near.png` 320 0 120 780. The floor does show board lines (`F2_few_P_noon_rail.png` 450 60 1100 60), better than new.
6. Holds at distance: PASS (soft).

Lamplight: `F2_few_P_saloon_night.png` is near-black with dim red streaks.

**Grade: game.**

### Set Q
1. Real stuff: PASS.
2. Age reads: FAIL. Same as new Q. `F2_few_Q_near.png` 0 0 1400 780.
3. No tile tells: PASS.
4. Board to board: PASS.
5. Edges and joints: FAIL. `F2_few_Q_near.png` 320 0 120 780.
6. Holds at distance: PASS (soft).

Lamplight: `F2_few_Q_saloon_night.png` is readable, a mahogany red.

**Grade: game.**

**Better set: Q, within a grade.**

**One change that moves it up most:** make "a few years" visible: a dulled, scuffed finish with dust in the grooves and rubbed patches at hand and boot height, plus joints that have opened slightly.

## F2_old

### Set P
1. Real stuff: FAIL. At noon it is a convincing dark old boarded wall, but by lamplight it is a black rectangle with a trace of red and reads as nothing. `F2_old_P_saloon_night.png` 250 0 900 780.
2. Age reads: PASS. Clearly different from new and few: opened black joints, darker and duller boards. It still lacks wear, splash and rubbed arrises.
3. No tile tells: PASS. The crackle web is barely visible at this darkness.
4. Board to board: PASS. Narrow boards with distinct tone and figure.
5. Edges and joints: PASS. Real dark gaps; ruler-straight and of one width, with no worn arris.
6. Holds at distance: PASS. `F2_old_P_far.png` keeps the board rhythm; a little regular.

**Grade: game** (upper end; the noon crop alone would be near the yardstick).

### Set Q
1. Real stuff: PASS. Readable in all four crops.
2. Age reads: PASS. As P, plus crazing in the finish.
3. No tile tells: FAIL. A uniform crackle web of thin dark lines lies over every board at the same scale and strength; it reads as an overlay. `F2_old_Q_near.png` 330 60 300 500.
4. Board to board: PASS.
5. Edges and joints: PASS. Same note on straight, uniform gaps.
6. Holds at distance: PASS. Faint dotting from the crackle at 5 m, `F2_old_Q_far.png` 0 20 560 300.

**Grade: game** (upper end).

**Better set: Q, narrowly and within a grade.** It reads as wood by lamplight where P goes black; P hides the crackle web better.

**One change that moves it up most:** break up the crackle so it lives in patches (thin on some boards, absent on others, following the grain) and add wear where hands and feet go, with rounded, lighter arrises at the joints.

**Best age of the swatch:** old. It is the only one that reads as separate boards.
