# ElevenLabs Audio Isolation

> Isolate audio tracks using ElevenLabs advanced audio isolation technology.


## Overview

- **Endpoint**: `https://fal.run/fal-ai/elevenlabs/audio-isolation`
- **Model ID**: `fal-ai/elevenlabs/audio-isolation`
- **Category**: audio-to-audio
- **Kind**: inference
**Tags**: audio



## Pricing

- **Price**: $0.1 per minutes

For more details, see [fal.ai pricing](https://fal.ai/pricing).

## API Information

This model can be used via our HTTP API or more conveniently via our client libraries.
See the input and output schema below, as well as the usage examples.


### Input Schema

The API accepts the following input parameters:


- **`audio_url`** (`string`, _optional_):
  URL of the audio file to isolate voice from
  - Examples: "https://v3.fal.media/files/zebra/zJL_oRY8h5RWwjoK1w7tx_output.mp3"

- **`video_url`** (`string`, _optional_):
  Video file to use for audio isolation. Either `audio_url` or `video_url` must be provided.



**Required Parameters Example**:

```json
{}
```

**Full Example**:

```json
{
  "audio_url": "https://v3.fal.media/files/zebra/zJL_oRY8h5RWwjoK1w7tx_output.mp3"
}
```


### Output Schema

The API returns the following output format:

- **`audio`** (`File`, _required_):
  The generated audio file
  - Examples: {"url":"https://v3.fal.media/files/zebra/zJL_oRY8h5RWwjoK1w7tx_output.mp3"}

- **`timestamps`** (`list<void>`, _optional_):
  Timestamps for each word in the generated speech. Only returned if `timestamps` is set to True in the request.
  - Array of void



**Example Response**:

```json
{
  "audio": {
    "url": "https://v3.fal.media/files/zebra/zJL_oRY8h5RWwjoK1w7tx_output.mp3"
  }
}
```


## Usage Examples

### cURL

```bash
curl --request POST \
  --url https://fal.run/fal-ai/elevenlabs/audio-isolation \
  --header "Authorization: Key $FAL_KEY" \
  --header "Content-Type: application/json" \
  --data '{}'
```

### Python

Ensure you have the Python client installed:

```bash
pip install fal-client
```

Then use the API client to make requests:

```python
import fal_client

def on_queue_update(update):
    if isinstance(update, fal_client.InProgress):
        for log in update.logs:
           print(log["message"])

result = fal_client.subscribe(
    "fal-ai/elevenlabs/audio-isolation",
    arguments={},
    with_logs=True,
    on_queue_update=on_queue_update,
)
print(result)
```

### JavaScript

Ensure you have the JavaScript client installed:

```bash
npm install --save @fal-ai/client
```

Then use the API client to make requests:

```javascript
import { fal } from "@fal-ai/client";

const result = await fal.subscribe("fal-ai/elevenlabs/audio-isolation", {
  input: {},
  logs: true,
  onQueueUpdate: (update) => {
    if (update.status === "IN_PROGRESS") {
      update.logs.map((log) => log.message).forEach(console.log);
    }
  },
});
console.log(result.data);
console.log(result.requestId);
```
